## 🩺 System Overview
Doctor Serial Rx (Prescription Chamber Management) streamlines private doctor chambers and specialist outpatient clinics. Built with **React 18**, **Hono**, and **Cloudflare D1**, the platform replaces manual paper token books and handwriting illegibility with real-time patient queues and printed e-prescriptions.

### Key Capabilities
1. **28,000+ Bangladesh Medicine Autocomplete Index:** High-speed client-side prefix search over local pharma brands (Beximco, Square, Incepta, Renata) with generic names, strengths, and standard dosage intervals (১+০+১ খাওয়ার পর).
2. **Zero-Duplicate Phone Queue:** Automatically links returning patients by phone number while allowing family branch profiles.
3. **Calibrated Layout Print Engine:** Pixel-perfect support for both 80mm thermal receipts (serial tokens) and standard A4/A5 prescription pads.
